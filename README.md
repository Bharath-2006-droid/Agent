# 🤖 BHARATH'S BOT

An intelligent AI assistant built with **FastAPI**, **Next.js**, **React**, **TypeScript**, and **Ollama**, featuring a futuristic 3D interface powered by **React Three Fiber**.

## ✨ Features

- 💬 AI Chat Interface
- 🧠 Conversation Memory
- ⚡ FastAPI Backend
- 🦙 Ollama Local LLM Integration
- 🌐 Modern Next.js Frontend
- 🎨 Futuristic 3D Quantum AI Core
- 📁 Planned Document Intelligence (RAG)
- 🔍 Planned Browser Agent
- 🤖 Extensible AI Agent Architecture

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Bharath-2006-droid/Agent.git
cd Agent
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```
